How to read this

Start with the Document Tree: it shows the nesting of every element (so you can see, for example, that <link> belongs in <head>, not <body>). Every name in the tree links to its full entry.

Each entry then gives: a plain-language description, a Goes inside / Can contain placement box, a usage example, and every element-specific attribute with its values (attribute in teal, value in amber).

The attributes shared by all elements (id, class, style, data-*, event handlers…) are written out in full once, in Global Attributes; every entry just lists their names.

At the end, an Attribute Index lists every attribute alphabetically with the elements it belongs to — the reverse lookup, for when you start from an attribute instead of a tag.

To print or save as PDF use Ctrl/Cmd + P — each section starts on a new page.

Document Structure & Root

The skeleton every page is built on. <!DOCTYPE> comes first, then a single <html> wrapping a <head> and a <body>.

<!DOCTYPE>#

Goes insideThe very first line of the document, before <html>.
Can containNothing — it is a declaration, not an element.

The document type declaration. It is NOT an HTML tag; it is an instruction to the browser telling it which version of HTML the page uses. It must be the very FIRST thing in the document, before <html>. In modern HTML, its only job is to keep the browser in "standards mode" (correct, spec-compliant rendering) rather than "quirks mode" (legacy bug-compatible rendering). It is case-insensitive and has no closing tag.

<!DOCTYPE html>
The modern HTML5 doctype takes no attributes. Just write <!DOCTYPE html>.

Legacy doctypes you may still encounter (do not use for new pages):
    <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN"
        "http://www.w3.org/TR/html4/strict.dtd">  - HTML 4.01 Strict
    <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN"
        "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">  - XHTML 1.0

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

<html>#

Goes insideThe document root; only <!DOCTYPE> may precede it.
Can containExactly one <head> followed by one <body>.

The root element of the page. Everything except the <!DOCTYPE> lives inside it. There must be exactly one per document, and it should contain exactly one <head> followed by one <body>. Setting the lang attribute here is strongly recommended for accessibility and SEO. This element accepts global attributes; the key ones are below.

<html lang="en">
    <head></head>
    <body></body>
</html>
lang — The primary language of the entire document. Inherited by all
       descendants unless they override it. (See lang in 00-global-attributes.html.)
    lang="en" — English.
    lang="en-GB" — British English.
    lang="de" — German.
xmlns — The XML namespace. Only required when serving the document as
        XHTML (application/xhtml+xml). Ignored for normal text/html pages.
    xmlns="http://www.w3.org/1999/xhtml" — The XHTML namespace.

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

<head>#

Goes insideDirectly inside <html>, as its first child.
Can containMetadata: <title>, <base>, <meta>, <link>, <style>, <script>, <noscript>, <template>.

A container for metadata: information ABOUT the document that is not displayed in the page content itself. Holds the <title>, <meta> tags, <link> tags (stylesheets, icons), <style>, and <script> elements. Must be the first child of <html>. This element has no element-specific attributes; it accepts global ones.

<head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>Page Title</title>
    <link rel="stylesheet" href="styles.css" />
</head>

No element-specific attributes. See 11-meta-info.html for the elements that go INSIDE <head> (<meta>, <base>, etc.).

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

<body>#

Goes insideDirectly inside <html>, after <head>.
Can containFlow content (most visible page elements).

Contains all the content that is actually rendered on the page: text, images, links, tables, etc. There must be exactly one <body>, and it must follow <head>. Window-level event handlers (onload, onresize, onunload) are conventionally placed here. This element accepts global attributes plus several window event handlers.

<body>
    <h1>Welcome</h1>
    <p>This is the page content.</p>
</body>
onload — Runs JavaScript after the page and all its resources finish loading.
    onload="init()" — Calls init() once everything is ready.
onunload / onbeforeunload — Run when the user is leaving the page.
    onbeforeunload="return confirm()" — Can prompt before navigating away.
Deprecated presentational attributes (do NOT use; use CSS instead):
    bgcolor, background, text, link, vlink, alink — colors and background.

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

<!--...-->#

Goes insideAlmost anywhere in the markup.
Can containPlain text only; cannot be nested.

An HTML comment. Anything between <!-- and --> is ignored by the browser and not rendered. Use comments to annotate your markup, leave notes for other developers, or temporarily disable a block of HTML. IMPORTANT: comments are visible to anyone who views the page source, so never put secrets in them. Comments cannot be nested, and the text inside must not contain the sequence "--".

<!-- This is a comment. It will not appear on the page. -->

<!--
    Comments can
    span multiple lines.
-->

<!-- <p>This paragraph is temporarily disabled.</p> -->

A comment has no tags, attributes, or values; it is just delimited text.

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

The Document Head — Metadata

These live inside <head>. They describe the page and load resources, but are not rendered in the page body.

<title>#

Goes insideInside <head> (exactly one per document).
Can containText only.

Defines the title of the document. It is shown in the browser tab, used as the default name when bookmarking, and is one of the most important pieces of text for SEO (it becomes the clickable headline in search results). There must be exactly one <title>, inside <head>. It may contain only text. This element has no element-specific attributes.

<title>My Website - Home</title>

No element-specific attributes. The content should be concise and descriptive; aim for roughly 50-60 characters for search-result display.

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

<base>#

Goes insideInside <head>, before any element that uses a URL (one per document).
Can containEmpty — it is a void element with no content.

Specifies a BASE URL and/or a default target for ALL relative URLs in the document. There can be at most ONE <base> per page, and it must appear in <head> before any element that uses a URL. It is a void element. Use with care: it affects every relative link, image, and form on the page.

<base href="https://example.com/app/" target="_blank" />
href — The base URL against which all relative URLs in the document resolve.
    href="https://example.com/docs/" — A relative href="page.html" now resolves
                 to https://example.com/docs/page.html.
target — The default target for all hyperlinks and forms that do not specify
         their own target.
    target="_self" — (default) Same browsing context.
    target="_blank" — Open links in a new tab/window by default.
    target="_parent" — The parent browsing context.
    target="_top" — The full window.

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

<meta>#

Goes insideInside <head> (some, like itemprop, may appear in <body>).
Can containEmpty — it is a void element with no content.

Represents a piece of METADATA that cannot be expressed by other head elements. It is a void element, and what it does depends on which of its attributes you use: charset, name+content, http-equiv+content, or property+content (for social/Open Graph data).

<meta charset="UTF-8" />
<meta name="description" content="A concise summary of the page for search engines." />
<meta name="viewport" content="width=device-width, initial-scale=1" />
<meta property="og:title" content="Shareable Title" />
charset — Declares the document's character encoding. Should be the FIRST
          thing in <head>. Always use UTF-8 for modern pages.
    charset="UTF-8" — Unicode (UTF-8) encoding.
name — Names a document-level metadata property; its value goes in "content".
    name="description" — A summary used by search engines (in results snippets).
    name="keywords" — A comma-separated keyword list (largely ignored by search now).
    name="author" — The page author's name.
    name="viewport" — Controls layout on mobile (see content examples below).
    name="robots" — Instructions for search-engine crawlers.
    name="theme-color" — Suggests a browser UI color (mobile address bar).
    name="referrer" — Sets the default referrer policy for the page.
    name="generator" — The software that generated the page.
content — The VALUE associated with the name, http-equiv, or property attribute.
          Its meaning depends on which it pairs with.
    content="width=device-width, initial-scale=1" — (with name="viewport")
                 Match the device width and start at 100% zoom. Essential for
                 responsive design.
    content="noindex, nofollow" — (with name="robots") Do not index this page
                 and do not follow its links.
    content="A short page summary." — (with name="description") The summary text.
    content="#0b5fff" — (with name="theme-color") A theme color.
http-equiv — Provides a pragma directive equivalent to certain HTTP response
             headers; the directive's value goes in "content".
    http-equiv="refresh" — Reload/redirect after a delay (content="5" or
                 content="5; url=https://example.com").
    http-equiv="content-security-policy" — Declare a CSP for the page.
    http-equiv="x-ua-compatible" — Legacy Internet Explorer rendering mode.
property — (not in the base HTML spec, but the de-facto standard for Open Graph
           and similar protocols) Names a property; value goes in "content".
    property="og:title" — Title used when shared on social platforms.
    property="og:description" — Description for social shares.
    property="og:image" — Preview image URL for social shares.
    property="og:url" — Canonical URL for the shared object.
    property="og:type" — The object type (e.g. "website", "article").
media — (used with name="theme-color") Apply the value only when a media query
        matches, e.g. for light vs dark mode.
    media="(prefers-color-scheme: dark)" — Theme color for dark mode.

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

<link>#

Goes insideInside <head>; body-OK rel types may also appear in <body>.
Can containEmpty — it is a void element with no content.

Defines a relationship between the current document and an EXTERNAL resource. It lives in <head> and is a void element. Its most common job is loading a stylesheet, but it also declares icons, preloads/prefetches resources, sets canonical URLs, and more. The rel attribute determines its purpose.

<link rel="stylesheet" href="styles.css" />
<link rel="icon" href="/favicon.ico" sizes="any" />
<link rel="canonical" href="https://example.com/page" />
rel — REQUIRED. The relationship/type, which defines what the link does.
    rel="stylesheet" — Load an external CSS file.
    rel="icon" — The page's favicon / tab icon.
    rel="apple-touch-icon" — Home-screen icon for iOS devices.
    rel="canonical" — The preferred (canonical) URL for duplicate content.
    rel="alternate" — An alternate version (e.g. an RSS feed or another language).
    rel="preload" — Fetch a critical resource early (requires the "as" attribute).
    rel="prefetch" — Fetch a resource likely needed for a FUTURE navigation.
    rel="preconnect" — Open an early connection to another origin.
    rel="dns-prefetch" — Resolve another origin's DNS early.
    rel="modulepreload" — Preload a JavaScript module.
    rel="manifest" — Link the web app manifest (PWA).
    rel="author" — Link to the author/about page.
    rel="license" — Link to the content's license.
    rel="next" / rel="prev" — Sequence relationships for paginated content.
    rel="search" — Link to an OpenSearch description document.
href — The URL of the linked resource.
    href="/css/main.css" — A stylesheet on this site.
    href="https://cdn.example.com/lib.css" — A cross-origin resource.
type — The MIME type of the linked resource.
    type="text/css" — A CSS stylesheet.
    type="image/x-icon" — An icon file.
    type="application/rss+xml" — An RSS feed (with rel="alternate").
media — A media query controlling WHEN the resource applies (mainly for
        stylesheets and icons).
    media="screen" — Apply on screens.
    media="print" — Apply only when printing.
    media="(max-width: 600px)" — Apply only on small viewports.
sizes — For icons, the pixel sizes the icon is designed for.
    sizes="any" — Scalable (e.g. an SVG/ICO icon).
    sizes="32x32" — A 32x32 icon.
    sizes="180x180" — A 180x180 touch icon.
as — REQUIRED with rel="preload"/"prefetch": the type of resource, so the
     browser sets the right priority and request headers.
    as="style" — Preloading a stylesheet.
    as="script" — Preloading a script.
    as="font" — Preloading a font (also requires crossorigin).
    as="image" — Preloading an image.
    as="fetch" — Preloading data fetched via fetch()/XHR (requires crossorigin).
crossorigin — Whether the resource is fetched with a CORS request. (See the
              example you started with - this is the same attribute.)
    crossorigin="anonymous" — CORS request without credentials.
    crossorigin="use-credentials" — CORS request WITH credentials.
integrity — A cryptographic hash (Subresource Integrity) the fetched resource
            must match, or the browser refuses to use it. Guards against
            tampered CDN files. Requires crossorigin for cross-origin URLs.
    integrity="sha384-BASE64HASH..." — Expected hash of the resource.
hreflang — The language of the linked resource.
    hreflang="en" — The resource is in English.
    hreflang="es" — The resource is in Spanish.
referrerpolicy — Referrer policy used when fetching the resource.
    referrerpolicy="no-referrer" — Send no Referer header.
    referrerpolicy="origin" — Send only the origin.
disabled — Boolean. For rel="stylesheet", load it in a disabled state (can be
           toggled on later via JavaScript).
    disabled — The stylesheet is initially inactive.
fetchpriority — Hints the relative priority of the fetch.
    fetchpriority="high" / "low" / "auto" — Loading-priority hint.
imagesrcset / imagesizes — With rel="preload" as="image", preload a RESPONSIVE
    image by mirroring an <img>'s srcset/sizes.
    imagesrcset="hero-480.jpg 480w, hero-960.jpg 960w" — Candidate sources.
    imagesizes="100vw" — Display-size hint for selection.

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

<style>#

Goes insideUsually inside <head>.
Can containCSS text.

Embeds CSS rules directly in the document (usually in <head>). Use it for page-specific styles or critical CSS; for site-wide styles prefer an external file via <link rel="stylesheet">. A scoped "title" can mark it as an alternate stylesheet.

<style>
    body { font-family: sans-serif; }
    .highlight { background: yellow; }
</style>
media — A media query limiting WHEN these styles apply.
    media="screen" — Apply on screens.
    media="print" — Apply only when printing.
    media="(max-width: 600px)" — Apply only on small viewports.
type — The styling language. Optional and effectively always CSS.
    type="text/css" — CSS (the only supported value; can be omitted).
title — Names a set of alternate stylesheets the user can switch between.
    title="Dark theme" — Marks this as a selectable alternate style set.
nonce — A cryptographic nonce that lets this inline style pass a strict
        Content-Security-Policy.
    nonce="r4nd0mValue" — Must match the CSP's style-src nonce.
blocking — Marks the stylesheet as render-blocking until parsed.
    blocking="render" — Block rendering until this style is processed.

Sectioning & Headings

Landmark regions and headings that give the page its outline. All sit in the flow content of <body>.

<h1> to <h6>#

Goes insideFlow content, and inside <hgroup>, <legend>, <summary>.
Can containPhrasing content (text and inline elements).

Section headings, ranked by importance: <h1> is the most important (top-level) and <h6> the least. They define the document's outline, which screen readers and search engines use to understand structure. Use ONE <h1> per page (the main title) and do not skip levels purely for visual size (control size with CSS, not by choosing a different heading level). These elements have no element-specific attributes.

<h1>Main Page Title</h1>
<h2>Major Section</h2>
<h3>Subsection</h3>
<h4>Sub-subsection</h4>
<h5>Minor heading</h5>
<h6>Least important heading</h6>

No element-specific attributes. The obsolete "align" attribute (left/center/right/justify) must not be used; style with CSS text-align instead.

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

<hgroup>#

Goes insideFlow content.
Can containOne heading (<h1>–<h6>) plus optional <p> elements.

Groups a single heading (<h1>-<h6>) together with related content such as a subtitle/tagline expressed in one or more <p> elements, so they are treated as one heading unit. This element has no element-specific attributes.

<hgroup>
    <h1>The Daily Times</h1>
    <p>All the news that fits</p>
</hgroup>

No element-specific attributes.

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

<header>#

Goes insideFlow content; not inside another <header>/<footer> or <address>.
Can containFlow content (no <header>/<footer> descendants).

Introductory content for its nearest sectioning ancestor (the page, an <article>, or a <section>) - typically a logo, site title, and/or primary navigation, or an article's heading and byline. A page can have several <header>s (one per section). It must not be nested inside another <header> or a <footer>. This element has no element-specific attributes.

<header>
    <h1>My Blog</h1>
    <nav><a href="/">Home</a> <a href="/about">About</a></nav>
</header>

No element-specific attributes.

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

<nav>#

Goes insideFlow content.
Can containFlow content (most visible page elements).

A semantic section containing major navigation links - a primary menu, a table of contents, pagination, breadcrumbs. It helps assistive technology identify and jump to navigation. Reserve it for MAJOR blocks of links, not every group of links on the page (a footer's minor links rarely need it). This element has no element-specific attributes.

<nav aria-label="Primary">
    <ul>
        <li><a href="/">Home</a></li>
        <li><a href="/about">About</a></li>
        <li><a href="/contact">Contact</a></li>
    </ul>
</nav>

No element-specific attributes. (Using aria-label, a global ARIA attribute, is recommended when a page has more than one <nav> so each can be told apart.)

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

<main>#

Goes insideFlow content; one per page; not inside article/aside/header/footer/nav.
Can containFlow content (most visible page elements).

Wraps the DOMINANT, unique content of the document - the central topic, not repeated chrome like the site header, nav, or footer. There must be only ONE visible <main> per page, and it should not be nested inside <article>, <aside>, <footer>, <header>, or <nav>. Helps screen-reader users skip to the main content. This element has no element-specific attributes.

<main>
    <h1>Article Title</h1>
    <p>The primary content of the page goes here.</p>
</main>

No element-specific attributes.

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

<section>#

Goes insideFlow content.
Can containFlow content (usually led by a heading).

A standalone THEMATIC grouping of content, typically with its own heading - a chapter, a tabbed panel, a distinct part of a page. Use it when the content forms a section of a larger whole. If the content is independently distributable, use <article>; if it is just a styling wrapper, use <div>. This element has no element-specific attributes.

<section>
    <h2>Features</h2>
    <p>Details about product features.</p>
</section>

No element-specific attributes (almost always should contain a heading).

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

<article>#

Goes insideFlow content.
Can containFlow content (most visible page elements).

A self-contained, independently distributable composition - a blog post, a news story, a forum post, a product card, a comment. A good test: would it still make sense if syndicated on its own (e.g. in an RSS feed)? Articles can be nested (e.g. comments inside a post). This element has no element-specific attributes.

<article>
    <h2>Breaking News</h2>
    <p>The full story...</p>
</article>

No element-specific attributes.

+ global attributes id, class, style, title, lang, dir, hidden, tabindex, accesskey, contenteditable, draggable, spellcheck, translate, inputmode, enterkeyhint, inert, popover, data-*, and on* event handlers — full list below.

<aside>#

Goes insideFlow content.
Can containFlow content (most visible page elements).

A <form> and the controls it can contain. Some (<select>) have their own required children.

<form>#

Goes insideFlow content; must not be nested inside another <form>.
Can containFlow content (the controls), but no nested <form>.

A container that groups input controls and defines how their data is collected and sent to a server when submitted. Everything the user fills in within the form is gathered into name=value pairs and transmitted according to the method and action attributes.

<form action="/submit" method="post">
    <input type="text" name="username" />
    <button type="submit">Send</button>
</form>
action — The URL that processes the submitted form data. If omitted, the form
         submits to the current page URL.
    action="/login" — Send data to the /login endpoint.
    action="https://api.example.com/save" — Send to an absolute URL.
method — The HTTP method used to submit the form.
    method="get" — (default) Appends data to the URL as a query string. Use
                 for searches/idempotent requests; data is visible in the URL.
    method="post" — Sends data in the request body. Use for changes/sensitive
                 data; not stored in browser history or the URL.
    method="dialog" — When the form is inside a <dialog>, submitting closes
                 the dialog and sets its returnValue instead of sending data.
enctype — How the form data is encoded; only matters when method="post".
    enctype="application/x-www-form-urlencoded" — (default) Standard encoding.
    enctype="multipart/form-data" — REQUIRED when the form contains a file
                 input (<input type="file">).
    enctype="text/plain" — Minimal encoding; for debugging, not real use.
name — A name for the form, allowing it to be referenced (e.g. document.forms).
    name="checkoutForm" — Names this form.
target — Where to display the response after submitting.
    target="_self" — (default) Same browsing context.
    target="_blank" — A new tab/window.
    target="_parent" — The parent frame.
    target="_top" — The full window, breaking out of all frames.
autocomplete — Whether the browser may autofill controls in this form.
    autocomplete="on" — (default) Allow autofill.
    autocomplete="off" — Disable autofill for the whole form.
novalidate — Boolean. If present, the browser skips built-in validation
             (required, type, pattern, etc.) when the form is submitted.
    novalidate — Submit without validating.
accept-charset — The character encoding(s) accepted by the server.
    accept-charset="UTF-8" — Tell the server data is UTF-8 encoded.

<input>#

Goes insidePhrasing content.
Can containEmpty — it is a void element with no content.

The most versatile form control. Its TYPE attribute decides what kind of control it is - a text box, checkbox, date picker, color swatch, file chooser, and many more. It is a void element. Which other attributes apply depends on the type.

<input type="email" name="email" placeholder="you@example.com" required />

    type="text" — (default) A single-line text field.
    type="password" — Text field that masks the entered characters.
    type="email" — Text field validated as an email address.
    type="url" — Text field validated as a URL.
    type="tel" — Telephone-number field (no built-in validation; shows phone
                 keypad on mobile).
    type="search" — Search field; may show a clear ("x") button.
    type="number" — Numeric field with spinner controls; supports min/max/step.
    type="range" — A slider; supports min/max/step. Value is imprecise by design.
    type="checkbox" — A toggle that can be checked/unchecked; use checked, value.
    type="radio" — One choice among a group sharing the same name attribute.
    type="date" — A date picker (year-month-day).
    type="time" — A time picker (hours, minutes).
    type="datetime-local" — Date and time picker with no timezone.
    type="month" — A year-and-month picker.
    type="week" — A year-and-week picker.
    type="color" — A color picker; value is a hex color like #ff0000.
    type="file" — A file chooser; pair with accept and multiple.
    type="hidden" — Not shown to the user; submits a fixed value.
    type="submit" — A button that submits the form; label set via value.
    type="reset" — A button that resets all controls to their defaults.
    type="button" — A generic push button with no default behavior (use JS).
    type="image" — A graphical submit button; uses src, alt, width, height.
name — The key under which this control's value is submitted. Without a name,
       the control's value is NOT sent. Radio buttons in one group share a name.
    name="firstName" — Submits as firstName=<value>.
value — The control's current value. Meaning varies by type.
    value="hello" — Initial text for text-like inputs.
    value="newsletter" — The value sent when a checkbox/radio is checked.
    value="Submit" — The visible label for submit/reset/button types.
placeholder — Hint text shown inside an empty text-like field. It is NOT a
              substitute for a <label>.
    placeholder="Search products..." — Greyed-out hint.
required — Boolean. The form cannot be submitted unless this control is filled
           in / checked.
    required — Field must have a value.
disabled — Boolean. The control is greyed out, non-interactive, and its value
           is NOT submitted.
    disabled — Turn the control off entirely.
readonly — Boolean. The value cannot be edited by the user but IS still
           submitted (unlike disabled). Not valid for checkbox/radio/file/buttons.
    readonly — Display a fixed value the user can copy but not change.
checked — Boolean. For type="checkbox" / type="radio", makes it selected by
          default when the page loads.
    checked — Pre-select this checkbox/radio.
min / max — The minimum and maximum allowed values for numeric, range, and
            date/time types.
    min="0"  — Smallest accepted number/date.
    max="100" — Largest accepted number/date.
step — The granularity for numeric, range, and date/time inputs.
    step="1" — Only whole-number increments.
    step="0.01" — Allow two decimal places (e.g. currency).
    step="any" — No stepping constraint; any value allowed.
minlength / maxlength — The minimum and maximum number of characters for
                        text-like inputs.
    minlength="8" — At least 8 characters.
    maxlength="20" — No more than 20 characters.
pattern — A regular expression the value must match (text-like types). Pair
          with title to explain the rule.
    pattern="[0-9]{5}" — Exactly five digits (e.g. a US ZIP code).
multiple — Boolean. Allows multiple values: several files (type="file") or
           several addresses (type="email").
    multiple — Accept more than one value.
accept — For type="file", which file types the chooser should accept.
    accept="image/*" — Any image type.
    accept=".pdf,.docx" — Specific file extensions.
    accept="image/png,image/jpeg" — Specific MIME types.
autocomplete — Hints what value the browser may autofill for this field.
    autocomplete="on" / "off" — Enable or disable autofill.
    autocomplete="email" — Fill with the user's saved email.
    autocomplete="current-password" — Fill the saved password.
    autocomplete="new-password" — Signals a password-creation field.
    autocomplete="name" / "tel" / "street-address" — Specific data tokens.
autofocus — Boolean. The control receives keyboard focus automatically when
            the page loads. Use at most once per page.
    autofocus — Focus this field on load.
list — The id of a <datalist> element providing autocomplete suggestions.
    list="browsers" — Connects to <datalist id="browsers">.
size — The visible width of a text-like input, measured in characters (not pixels).
    size="40" — Roughly 40 characters wide.
src / alt — For type="image" only: the image URL and its alternative text.
    src="submit.png" — The button image.
    alt="Submit" — Text alternative for the image button.
form — Associates the input with a <form> by id, even if it sits outside the
       form element in the DOM.
    form="myForm" — Submit with <form id="myForm">.
formaction / formmethod / formenctype / formtarget / formnovalidate -
    On submit-type inputs (submit/image), these OVERRIDE the parent <form>'s
    corresponding attributes for that one submission.
    formaction="/draft" — Submit this button to a different URL.
    formmethod="get" — Use GET for this button only.
    formnovalidate — Skip validation when submitting via this button.

<img>#

Goes insidePhrasing content, or inside a <picture>.
Can containEmpty — it is a void element with no content.

Embeds an image. It is a void element. The src and alt attributes are essential: src is the image source, and alt provides text shown if the image fails and read aloud by screen readers. For responsive images, use srcset + sizes (or wrap in <picture>).

<img src="photo.jpg" alt="A golden retriever catching a frisbee"
     width="640" height="480" loading="lazy" />
src — REQUIRED. The URL of the image to display.
    src="logo.png" — A relative URL.
    src="https://cdn.example.com/img/hero.jpg" — An absolute URL.
alt — Alternative text describing the image. REQUIRED for accessibility.
      Use an EMPTY value for purely decorative images so screen readers skip
      them.
    alt="Bar chart of 2026 sales" — Meaningful description.
    alt="" — Decorative image; intentionally ignored by assistive tech.
srcset — A set of candidate image sources for different resolutions/sizes,
         letting the browser pick the best one. Each entry is "URL descriptor".
    srcset="img-480.jpg 480w, img-960.jpg 960w" — Width descriptors (w).
    srcset="img.jpg 1x, img@2x.jpg 2x" — Pixel-density descriptors (x).
sizes — Tells the browser how wide the image will be displayed at various
        viewport sizes, so it can choose from srcset (used with w descriptors).
    sizes="(max-width: 600px) 100vw, 50vw" — Full width on small screens,
                 half width otherwise.
width / height — The intrinsic dimensions in pixels. Always set BOTH so the
        browser can reserve space and avoid layout shift while loading.
    width="800" — 800px wide.
    height="600" — 600px tall.
loading — When to load the image.
    loading="eager" — (default) Load immediately.
    loading="lazy" — Defer until the image nears the viewport (perf win for
                 below-the-fold images).
decoding — Hint for how to decode the image relative to rendering.
    decoding="auto" — (default) Browser decides.
    decoding="async" — Decode off the main thread to avoid blocking.
    decoding="sync" — Decode synchronously.
crossorigin — Whether to fetch the image with a CORS request (needed to use
              the image data in a <canvas> without "tainting" it).
    crossorigin="anonymous" — CORS request without credentials.
    crossorigin="use-credentials" — CORS request WITH credentials.
fetchpriority — Hints the relative loading priority.
    fetchpriority="high" — Prioritize (e.g. the LCP hero image).
    fetchpriority="low" — Deprioritize.
    fetchpriority="auto" — (default) Let the browser decide.
usemap — Associates the image with a client-side image <map> by its name,
         prefixed with "#".
    usemap="#planetmap" — Uses <map name="planetmap">.
ismap — Boolean. Only valid when the <img> is inside an <a>. Click
        coordinates are sent to the server as ?x,y (a server-side image map).
    ismap — Enable server-side image-map behavior.
referrerpolicy — How much referrer info to send when fetching the image.
    referrerpolicy="no-referrer" — Send no Referer header.
    referrerpolicy="origin" — Send only the origin.

media — (for <picture>) A media query; this source is used only if it matches.

    sizes="(max-width: 600px) 100vw, 50vw" — Display-width hints.

Global Attributes

Every element accepts these (a few have no visible effect on non-rendered elements like <head>). Each element entry above lists their names; here is the full detail.

id#

Assigns a unique identifier to the element. Must be unique within the whole document. Used as a CSS hook (#myid), a JavaScript lookup target (document.getElementById), and as a fragment link target (href="#myid").

<div id="main-header">...</div>
id — The value can be any string with no spaces. It is case-sensitive.
    id="main-header" — A descriptive, unique name for this one element.

class#

Assigns one or more class names to the element. Unlike id, the same class can be reused on many elements. Primary hook for CSS (.myclass) and for grouping elements in JavaScript (getElementsByClassName / querySelectorAll).

<p class="lead intro highlighted">...</p>
class — A space-separated list of one or more class names.
    class="btn" — A single class.
    class="btn btn-primary large" — Multiple classes applied at once.

style#

Applies inline CSS directly to this one element. Highest specificity of the normal CSS sources, so it overrides stylesheet rules. Generally avoid for maintainability; prefer classes. Useful for one-off or dynamic styling.

<span style="color: red; font-weight: bold;">...</span>
style — A string of CSS declarations (property: value; pairs).
    style="color: red;" — A single declaration.
    style="margin: 0; padding: 8px; background: #eee;" — Multiple declarations.

title#

Advisory information shown as a tooltip on hover. Also read by some assistive technologies. Do NOT rely on it for essential information, since it is not available on touch devices and is easy to miss.

<abbr title="HyperText Markup Language">HTML</abbr>
title — Any plain-text string. Newlines (&#10;) are honored in the tooltip.
    title="Click to expand" — A short hint.

lang#

Declares the human language of the element's content. Helps screen readers choose the correct pronunciation, helps search engines, and enables language-specific CSS (:lang()) and hyphenation/spellcheck behavior.

<p lang="fr">Bonjour le monde</p>
lang — A valid BCP 47 language tag.
    lang="en" — English.
    lang="en-US" — English, United States variant.
    lang="es" — Spanish.
    lang="zh-Hans" — Chinese, Simplified script.
    lang="" — Empty value means the language is unknown.

dir#

Sets the text directionality of the element's content.

<p dir="rtl">مرحبا بالعالم</p>
dir — Controls the base direction of text.
    dir="ltr" — Left-to-right (English, most European languages).
    dir="rtl" — Right-to-left (Arabic, Hebrew).
    dir="auto" — The browser decides based on the first strong directional
                 character in the content. Useful for user-generated text.

hidden#

Indicates the element is not yet, or no longer, relevant. The browser does not render hidden elements. Use it for content toggled by scripting rather than for things hidden purely for layout (use CSS for that).

<div hidden>This is not shown.</div>
<div hidden="until-found">Revealed by in-page find or scroll-to-text.</div>
hidden — A boolean-like attribute.
    hidden — (or hidden="") Element is fully hidden and removed from layout.
    hidden="until-found" — Element is hidden but can be revealed by the
                 browser's "find in page" feature or a scroll-to-text-fragment
                 link; fires a "beforematch" event when revealed.

tabindex#

Controls whether and in what order an element is focusable via the Tab key.

<div tabindex="0">Focusable div</div>
tabindex — An integer.
    tabindex="0" — Element becomes focusable and joins the natural tab order
                 in source order. Most common value for custom controls.
    tabindex="-1" — Element is focusable by script/click but is SKIPPED by
                 Tab navigation. Useful for focus targets like modal dialogs.
    tabindex="1" — (any positive number) Element is focused before tabindex="0"
                 elements, ordered by the number. Discouraged: it creates
                 confusing, hard-to-maintain tab orders.

accesskey#

Suggests a keyboard shortcut to activate or focus the element. The exact modifier keys vary by browser/OS (often Alt, or Alt+Shift, or Ctrl+Alt).

<button accesskey="s">Save</button>
accesskey — One or more single characters separated by spaces; the browser
            uses the first one it supports.
    accesskey="s" — Activates this element via the platform's accesskey combo.

contenteditable#

Makes the element's content directly editable by the user, turning it into a basic rich-text editing region.

<div contenteditable="true">Type here...</div>
contenteditable — Controls editability.
    contenteditable="true" — (or contenteditable="") Content is editable.
    contenteditable="false" — Content is not editable.
    contenteditable="plaintext-only" — Editable, but rich formatting is
                 stripped; only plain text is kept.

draggable#

Specifies whether the element can be dragged using the native HTML Drag-and-Drop API. Links and images are draggable by default.

<img src="logo.png" draggable="true" alt="Logo" />
draggable — Must be an explicit value (it is NOT a boolean attribute).
    draggable="true" — Element can be dragged.
    draggable="false" — Element cannot be dragged.

spellcheck#

Hints whether the element should be checked for spelling/grammar errors. Mainly relevant for editable content (inputs, textareas, contenteditable).

<textarea spellcheck="true"></textarea>
spellcheck — Controls spell checking.
    spellcheck="true" — (or spellcheck="") Enable spell checking.
    spellcheck="false" — Disable spell checking.

translate#

Tells translation tools whether the element's text should be translated.

<span translate="no">BrandName</span>
translate — Controls translation.
    translate="yes" — (or translate="") Content should be translated.
    translate="no" — Content should NOT be translated (brand names, code).

inputmode#

Hints which virtual keyboard layout to show on touch devices for editable elements. Does not affect validation; purely a UX hint.

<input inputmode="numeric" />
inputmode — Suggested keyboard type.
    inputmode="none" — No virtual keyboard (custom input UI).
    inputmode="text" — Standard text keyboard (default).
    inputmode="decimal" — Numeric keypad with a decimal separator.
    inputmode="numeric" — Digits only.
    inputmode="tel" — Telephone keypad.
    inputmode="search" — Text keyboard with a "Search" enter key.
    inputmode="email" — Text keyboard optimized for email (@ key).
    inputmode="url" — Text keyboard optimized for URLs (/ and . keys).

enterkeyhint#

Hints what label/icon the Enter key should show on a virtual keyboard.

<input enterkeyhint="search" />
enterkeyhint — Label for the Enter/Return action key.
    enterkeyhint="enter" — Insert a new line.
    enterkeyhint="done" — Nothing more to input; close the keyboard.
    enterkeyhint="go" — Take the user to the target of their input.
    enterkeyhint="next" — Move to the next field.
    enterkeyhint="previous" — Move to the previous field.
    enterkeyhint="search" — Submit a search.
    enterkeyhint="send" — Send a message.

inert#

Marks the element (and all its descendants) as inert: non-clickable, non-focusable, and hidden from assistive tech and find-in-page. Useful for "freezing" background content behind a modal.

<main inert>Background content behind an open dialog.</main>
inert — A boolean attribute (presence = on).
    inert — The subtree cannot be interacted with or focused.

popover#

Turns the element into a popover that can be shown on top of other content in the browser's top layer, controlled by a button with popovertarget.

<div id="menu" popover>Popover content</div>
<button popovertarget="menu">Toggle</button>
popover — Defines popover behavior.
    popover="auto" — (or popover="") Light-dismiss: closing on outside click
                 or Escape, and only one auto popover open per ancestor chain.
    popover="manual" — Stays open until explicitly closed; not light-dismissed.
    popover="hint" — Hint popover (e.g. tooltip-like), does not close other
                 auto popovers when shown.

data-*#

Custom data attributes. Store private, page-specific data on any element without affecting layout or semantics. Read in JS via element.dataset. The name after "data-" becomes a camelCased dataset key.

<article data-author-id="42" data-published-date="2026-01-01">...</article>
data-* — Any attribute whose name starts with "data-". The rest of the name
         must be lowercase and may contain hyphens.
    data-user-id="42" — Read in JS as element.dataset.userId.
    data-state="open" — Read as element.dataset.state; also CSS-selectable
                 via [data-state="open"].

EVENT HANDLER ATTRIBUTES#

These run JavaScript when an event fires. They are global (most apply to most elements). Inline handlers are convenient but addEventListener() in a separate script is generally preferred for maintainability and CSP safety. Below are the most commonly used ones grouped by category.

<button onclick="doSomething()">Click me</button>
Mouse / pointer events:
    onclick      — Element was clicked.
    ondblclick   — Element was double-clicked.
    onmousedown  — A mouse button was pressed over the element.
    onmouseup    — A mouse button was released over the element.
    onmouseover  — Pointer moved onto the element.
    onmouseout   — Pointer moved off the element.
    onmousemove  — Pointer moved while over the element.
    oncontextmenu- The context (right-click) menu was requested.
    onwheel      — The mouse wheel was rotated.

Keyboard events:
    onkeydown    — A key was pressed down.
    onkeyup      — A key was released.
    onkeypress   — (Deprecated) A character key was pressed.

Form / input events:
    oninput      — The value of an input/textarea changed (fires per keystroke).
    onchange     — The value changed AND the element lost focus / was committed.
    onsubmit     — A <form> is being submitted.
    onreset      — A <form> is being reset.
    onfocus      — The element gained focus.
    onblur       — The element lost focus.
    onselect     — Text inside an input/textarea was selected.
    oninvalid    — A form control failed validation.

Clipboard events:
    oncopy       — Content was copied.
    oncut        — Content was cut.
    onpaste      — Content was pasted.

Drag-and-drop events:
    ondragstart  — Dragging started on a draggable element.
    ondrag       — The element is being dragged.
    ondragenter  — A dragged item entered a valid drop target.
    ondragover   — A dragged item is over a valid drop target.
    ondragleave  — A dragged item left a valid drop target.
    ondrop       — A dragged item was dropped on a target.
    ondragend    — Dragging finished.

Window / document-level events (typically on <body>):
    onload       — The resource and its dependents finished loading.
    onunload     — The document is being unloaded.
    onresize     — The window was resized.
    onscroll     — The element/document was scrolled.
    onerror      — A resource failed to load.

Media events (on <audio>/<video>):
    onplay, onpause, onended, ontimeupdate, onvolumechange, onloadeddata,
    oncanplay, onseeking, onseeked, onwaiting, ondurationchange.

Obsolete / Deprecated Elements

Removed from HTML5 — kept here only so you recognize them in old code. Each notes its modern replacement.

<acronym>Deprecated#

removed in HTML5. Use <abbr> instead.

Was used to mark an acronym. Browsers showed a tooltip from the title attribute. <abbr> now covers both acronyms and abbreviations.

<abbr title="North Atlantic Treaty Organization">NATO</abbr>

Do not use <acronym>. Replace it with <abbr> (documented next).

<big>Deprecated#

removed in HTML5. Use CSS instead.

Was used to render text one size larger than surrounding text.

<span style="font-size: larger;">Bigger text</span>

Do not use <big>. Use CSS: font-size: larger; (or a specific size).

<center>Deprecated#

removed in HTML5. Use CSS instead.

Was a block element that horizontally centered its contents.

<div style="text-align: center;">Centered inline content</div>

Do not use <center>. Use CSS: text-align: center; for inline content, or margin: 0 auto; with a set width for block elements.

<font>Deprecated#

removed in HTML5. Use CSS instead.

Was used to set the font face, size, and color of text.

<span style="font-family: Arial; color: blue; font-size: 18px;">Styled text</span>

Do not use <font>. Its old attributes (color, face, size) are replaced by the CSS properties color, font-family, and font-size.

<strike>Deprecated#

removed in HTML5. Use <del> or <s> instead.

Was used to render strikethrough text.

<del>removed</del> <s>no longer accurate</s>

Do not use <strike>. Use <del> for an edit/deletion, <s> for outdated content, or CSS text-decoration: line-through; for purely visual strikethrough.

<tt>Deprecated#

removed in HTML5. Use CSS instead.

Was used for "teletype" monospace text.

<code>monospace</code>  <!-- or --> <span style="font-family: monospace;">text</span>

Do not use <tt>. Use a semantic element like <code>, <kbd>, <samp>, or <var> where appropriate, or CSS font-family: monospace; for plain monospace text.

<frameset>Deprecated#

removed in HTML5. Do not use.

Replaced the <body> element in old "frames" pages. It divided the window into a grid of independent <frame> regions, each loading a separate HTML document. Modern layouts use CSS (flexbox/grid) and, for embedding, <iframe>.

<frameset cols="25%,75%">
    <frame src="menu.html" />
    <frame src="content.html" />
</frameset>
cols — Defined the column layout as a comma-separated list of widths.
    cols="25%,75%" — Two columns at 25% and 75% width.
    cols="200,*" — A fixed 200px column and one filling the rest ("*").
rows — Defined the row layout the same way as cols, but vertically.
    rows="100,*" — A 100px top row and a remaining-space bottom row.

<frame>Deprecated#

removed in HTML5. Do not use.

Defined a single region within a <frameset>, loading its own document.

<frame src="page.html" name="contentFrame" />
src — The URL of the document to load into the frame.
    src="sidebar.html" — Loads sidebar.html in this frame.
name — A name used so links (target="...") could load pages into this frame.
    name="main" — Allows target="main" links to load here.
noresize — Boolean. Prevented the user from dragging to resize the frame.
    noresize — Lock the frame size.
scrolling — Whether scrollbars appeared.
    scrolling="yes" — Always show scrollbars.
    scrolling="no" — Never show scrollbars.
    scrolling="auto" — Show only when needed.
frameborder — Whether a border was drawn (1 = yes, 0 = no).
    frameborder="0" — No border.
marginwidth / marginheight — Inner margins in pixels.
    marginwidth="10" — 10px left/right padding inside the frame.

<noframes>Deprecated#

removed in HTML5. Do not use.

Provided fallback content for browsers that could not display frames. Obsolete because all browsers now support standard content.

<noframes>
    Your browser does not support frames. <a href="content.html">View content</a>.
</noframes>

No attributes. It simply held fallback HTML.

<dir>Deprecated#

removed in HTML5. Use <ul> instead.

Was an early element for directory/file listings, rendered as a list.

<ul>
    <li>file1.txt</li>
    <li>file2.txt</li>
</ul>

Do not use <dir>. Replace it with <ul>.

<basefont>Deprecated#

removed in HTML5. Use CSS instead.

Was placed in <head> to set a default font color, size, and face for the entire document.

<style>
    body { font-family: Arial, sans-serif; font-size: 16px; color: #222; }
</style>
Do not use <basefont>. Set document-wide typography with CSS on the body (or
:root) — font-family, font-size, and color - as shown above.

<applet>Deprecated#

removed in HTML5. Use <embed> or <object>.

Was used to embed a Java applet. Java applets are obsolete and unsupported by modern browsers. Embed media/plugins with <object>, <embed>, <iframe>, <video>, or <img> as appropriate.

<object data="content.pdf" type="application/pdf" width="600" height="400">
    Fallback content if the resource cannot be displayed.
</object>

Do not use <applet>. Replace it with <object> or <embed> (documented below), or a purpose-built element such as <iframe>/<video> depending on the content.
